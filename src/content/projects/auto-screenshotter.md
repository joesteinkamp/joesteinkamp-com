Design audits and competitive research both require the same tedious first step: screenshot every screen in a product. Auto Screenshotter automates that — install the extension, point it at an app, and it crawls the UI and captures each state without manual intervention.

Built to feed the design inspiration archive: run it against a product, get a full-coverage screenshot set, surface the patterns worth studying. A small tool that removes the friction between noticing a product and being able to analyze it.
