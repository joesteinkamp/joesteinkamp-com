Manually screenshotting a web app for documentation, audits, or handoff is tedious
and inconsistent. Auto Screenshotter automates the walk: install the extension,
point it at an app, and it navigates and captures every page systematically.

Useful for design audits, regression baselines, and building screenshot libraries
for AI training or analysis — the kind of work that gets skipped because the cost
of doing it manually is too high.
