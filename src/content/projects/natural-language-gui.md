Most UI components capture what a user did. This library captures what they meant.
Natural Language GUI wraps standard interface components so each interaction
produces a natural language description of itself — usable directly as AI context,
log output, or instruction stream.

The thesis: the gap between a user's intent and an AI's understanding is largely
a translation problem, and the interface layer is the right place to close it.
