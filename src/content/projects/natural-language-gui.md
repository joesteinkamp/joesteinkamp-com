The question this explores: what if a UI component wasn't wired to application
logic directly, but instead described what the user just did in plain language —
and let a model decide what to do with it?

Each component in the library emits a natural-language description of the
interaction rather than a typed event. Feeds directly into an agentic loop,
so the interface becomes a prompt surface rather than a form. An experiment in
what "AI-native UI" actually means at the component level.
