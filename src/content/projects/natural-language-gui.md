The question behind this project: what if a UI component didn't expose a props API but instead accepted a plain-English description of what it should do? Natural Language GUI is a component library built around that bet — each component interprets a natural-language prompt at render time rather than a rigid set of typed props.

Useful for prototyping flows where the exact UI shape is still undecided, and as a probe into where natural language falls short as a design specification. The sharper the prompt, the more predictable the output — which turns out to say something interesting about both AI and design.
