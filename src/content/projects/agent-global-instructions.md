Every AI coding agent benefits from knowing the same things: what the project builds,
how the codebase is structured, which moves are off-limits. But maintaining that context
separately for Claude, Copilot, and Gemini doesn't scale.

Agent Global Instructions is the single source for all of it — one repo, one install,
consistent agent behavior across tools. The natural successor to the narrower `agents-md`
starter kit, expanded to speak every agent's dialect.
