An evolution of the AGENTS.md starter kit: a single instruction layer that works
across Claude, Cursor, Gemini, and whatever agent surfaces come next. The interactive
customizer walks a project through the setup, generating the right files for its
context rather than shipping a one-size-fits-all template.

The goal is tool-agnostic context — the same project knowledge, surfaced correctly
regardless of which AI is reading it.
