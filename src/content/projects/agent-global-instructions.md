A single interactive customizer that generates the right instruction file for
whichever AI coding tool you use — Claude Code, Cursor, GitHub Copilot, or Gemini.
Fill in once, export to the format your tool expects.

A natural extension of the AGENTS.md work: once you have opinionated conventions
for how agents should behave, you want them to travel across tools rather than
being rewritten for each one.
