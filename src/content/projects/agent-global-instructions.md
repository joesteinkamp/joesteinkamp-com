Different agents read different files: Claude reads CLAUDE.md, Gemini reads GEMINI.md, and so on. Global Agent Instructions is a shared base that generates the right file for each tool from a single authoritative source — so the rules you write once actually apply everywhere.

Companion project to agents-md, aimed at teams running multiple agents on the same codebase.
