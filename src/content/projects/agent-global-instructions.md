One problem with bespoke CLAUDE.md files: they only work for Claude. This is the
same idea made portable — a single source of truth for how you work that compiles
down to the instruction format each AI tool actually reads.

Ships with an interactive setup script so you can drop a customized instruction
set into any project in one command, regardless of which agent you're working with.
A natural extension of the agents-md starter kit, oriented toward teams running
multiple AI tools at once.
