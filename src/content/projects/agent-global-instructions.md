An evolution of the agents-md idea, but tool-agnostic: a single portable instruction set that generates the right file for each AI coding tool — CLAUDE.md for Claude, AGENTS.md for Gemini, .cursorrules for Cursor — from one shared source of truth.

The interactive customizer lets you describe your project's conventions once and get the right context files for every AI coding environment you use. The core bet is that the contract between a developer and their AI tools shouldn't have to be rewritten for each tool — it should be authored once and adapted.
